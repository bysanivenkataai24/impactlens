deploying and get advice for commercial use.

## This project

ImpactLens is licensed under the **GNU Affero General Public License v3.0**
(`LICENSE`). Reason: its model runtime, Ultralytics, is AGPL-3.0, and the
service links to it. AGPL-3.0 section 13 requires that users interacting with a
modified version over a network can obtain its corresponding source; set
`SOURCE_URL` so the UI and `/health` link to it.
